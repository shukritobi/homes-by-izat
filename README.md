# Homes by Izat

Responsive static website for Izat / Homes by Izat.

## Purpose
- Showcase selected Kuala Lumpur Airbnb stays
- Send booking traffic to Izat's Airbnb listings
- Capture Airbnb business/tutorial leads through WhatsApp
- Centralize Airbnb, Instagram, Threads and WhatsApp

## Stack
Plain HTML, CSS and JavaScript. No build step is required.

## Deploy
Compatible with GitHub Pages or Cloudflare Pages. For GitHub Pages, deploy from the repository root on the `main` branch.

## Note
The preview uses externally hosted Kuala Lumpur/property imagery for presentation. Replace these with Izat's own listing photography for a production launch.
